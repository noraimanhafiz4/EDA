# 🔍 SQL Exploratory Data Analysis (EDA) Toolbox

## 📌 Project Overview
Exploratory Data Analysis (EDA) is the most critical step in understanding the "Why" behind the data. This repository is a curated library of **SQL analytical patterns** used to uncover trends, identify correlations, and extract actionable business intelligence from raw datasets.

## 📁 Repository Structure
* **[Time_Series/](scripts/time_series.sql):** Queries for Month-over-Month (MoM) growth, seasonality trends, and rolling averages.
* **[Customer_Analytics/](scripts/customer_insights.sql):** RFM (Recency, Frequency, Monetary) foundations, churn analysis, and retention tracking.
* **[Product_Performance/](scripts/product_analysis.sql):** Top-selling SKU analysis, category contribution, and price elasticity checks.
* **[Distribution_Stats/](scripts/descriptive_stats.sql):** Using SQL to calculate Median, Mode, and Percentiles for market segmentation.

## 🛠️ Advanced SQL Techniques Featured
* **Window Functions:** `RANK()`, `LEAD()`, `LAG()`, and `SUM() OVER()` for complex trend calculations.
* **Common Table Expressions (CTEs):** To breakdown multi-layered analytical questions into readable steps.
* **Subqueries & Joins:** For cross-referencing different business dimensions (e.g., Sales vs. Geography).
* **Conditional Aggregations:** Utilizing `CASE WHEN` to build dynamic market tiers and groups.

## 💡 The Business Value
In a business environment, the ability to quickly pivot data and find growth opportunities is invaluable. This toolbox demonstrates a structured approach to transforming raw rows into strategic insights.
